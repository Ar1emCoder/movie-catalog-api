# Movie Catalog API

RESTful API for managing movie catalog built with FastAPI and Docker.

##  Tech Stack
- Python 3.10+
- FastAPI
- SQLite / PostgreSQL
- Docker & Docker Compose
- Structured logging

## 🚀 Features
- CRUD operations for movies and genres
- Filtering and search
- Many-to-many relationships (movies <-> genres)
- Proper error handling and validation
